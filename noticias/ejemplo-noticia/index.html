Exemple de Notícia Sindical

13 de juny de 2026
← Tornar a les Notícies

Això és un exemple de notícia per demostrar el funcionament del sistema de notícies de La Intersindical VDD.

El sistema permet generar automàticament pàgines de notícies a partir de documents PDF, extreient el text i les imatges contingudes en ells.

Per crear una nova notícia, simplement executeu el script de generació amb l'ordre:

python generar.py "mi-noticia.pdf" --fecha 2026-06-13 --slug mi-noticia
